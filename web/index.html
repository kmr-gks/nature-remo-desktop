Remo Panel

設定

Nature Cloud API

home.nature.global で発行します。~/.remo-panel/config.json に保存されます。

ローカル接続（赤外線を直接送る・高速）

同一LANのときだけ使えます。設定するとクラウドを経由しない高速ボタンを登録できます。

赤外線の学習

物理リモコンを Remo に向けてボタンを押し、「信号を取得」を押します。

    公開範囲

    127.0.0.1 はこのPCのみ。0.0.0.0 にすると同一LANのスマホ等からも使えますが、 その場合はアクセスキーを必ず設定してください。変更後は再起動が必要です。
    設定すると ?k=キー を付けたURLでのみアクセスできます。
